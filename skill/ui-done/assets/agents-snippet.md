## UI Done

开始新的相关任务或接续已更新的 Skill 时，先检查当前选定包的 VERSION；与本对话上次实际读取的版本不同，或无法确认版本时，重新读取同一包的 SKILL.md 和当前阶段所需参考，再继续。文件更新、技能目录刷新与旧对话正文重读是不同状态，不宣称未取得回执的全部会话已重载。

工作涉及前端、网页或界面的观察、调研、设计、返修、实现或验收时，按当前技能列表定位并完整读取 ui-done/SKILL.md，以及当前阶段必读材料，再做相应工作；任务中途进入界面范围也适用。入口摘要、frontend-design 或单篇参考不替代完整入口。对当前界面的模糊不满按含义判断，不限固定说法；使用反馈澄清分支，有 get-clear 时由其负责逐问、详细需求理解报告及用户核对；用户补充则继续问并更新报告，明确认可后再实施。每次反馈及提问工具中的答案都重新判断，包括建议中尚未说清、会影响改法的关键用词或指代；已读不代表当前行动合规。具体故障直接调查修复；明确授权的自主设计继续执行；纯后端、普通聊天和技能维护不启动前端制作流程。同一对话有效内容可复用，压缩或交接后恢复所需依据。
